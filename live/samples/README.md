# Sample packages committed to this repo

This repo is PRIVATE and these files are here for personal use on the
owner's rig only.

- `lap-steel-v1.0.0/` — thinned from Indiginus THE STEEL, a commercially
  licensed Kontakt library. **Licence-restricted: must never appear in a
  public repo, release artifact, or downloadable build.** See its
  `NOTICE.txt` and `README.md`. It is deliberately NOT part of the CC0 /
  CC-BY acoustic pack and must not be merged into it.

The CC0/CC-BY packs (Acoustic Instruments v2.0.0 and its predecessors) are
NOT committed here — they live in the xentar repo and reach the engine via
the per-rate sample cache, like the factory sets.
